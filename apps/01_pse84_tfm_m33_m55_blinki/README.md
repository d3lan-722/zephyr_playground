# PSE84 TF-M dual-core blinky

Two standalone Zephyr applications that run side by side on the
`kit_pse84_eval` (PSE846GPS2DBZC4A) in the TF-M paired-build
configuration described in the Zephyr board docs:

<https://docs.zephyrproject.org/latest/boards/infineon/kit_pse84_eval/doc/index.html#tf-m-multicore-support>

| App        | Core              | LED            | Blink rate |
| ---------- | ----------------- | -------------- | ---------- |
| `cm33_ns/` | Cortex-M33, NS    | `led0` (red)   | 1 Hz       |
| `cm55/`    | Cortex-M55        | `led1` (green) | 2 Hz       |

Both images set `CONFIG_PSOC_EDGE_M55_SRF_SUPPORT=y` in their
`prj.conf`. This enables the mailbox/relay glue so the CM55
non-secure image can reach the same TF-M Secure Processing
Environment that the CM33-NS image already talks to locally.

> Note: in this multicore mode the CM55 image is **not** built with
> `--sysbuild`. Both images are standalone Zephyr apps; they are
> coordinated through the `PSE84_CM33_BUILD_DIR` CMake variable and
> are flashed independently.

## Prerequisites

* `BOOT SW` on the board set to `ON` (boot from external flash).
* Infineon OpenOCD available to `west flash`. If not already
  configured, point west at it once:

  ```bash
  west config build.cmake-args -- "-DOPENOCD=/usr/local/openocd/bin/openocd"
  ```

* The Zephyr workspace must contain the `trusted-firmware-m`,
  `tf-m-tests` and `tf-psa-crypto` modules (already enabled in this
  repository's `.devcontainer/west.yml`).

## Build

Order matters: the CM55 build consumes PSA headers generated by the
CM33-NS TF-M build, so the CM33-NS image is built first.

### 1. CM33 non-secure (TF-M)

```bash
cd apps/01_pse84_tfm_m33_m55_blinki/cm33_ns
west build -p always -b kit_pse84_eval/pse846gps2dbzc4a/m33/ns
```

Output of interest: `build/zephyr/tfm_merged.hex`.

### 2. CM55

Pass the absolute path of the CM33-NS build directory to the CM55
build via `PSE84_CM33_BUILD_DIR`:

```bash
cd apps/01_pse84_tfm_m33_m55_blinki/cm55
west build -p always -b kit_pse84_eval/pse846gps2dbzc4a/m55 -- \
    -DPSE84_CM33_BUILD_DIR=$(realpath ../cm33_ns/build)
```

Output of interest: `build/zephyr/zephyr.signed.hex`.

## Flash

The CM33-NS image jumps to the CM55 image on boot, so the CM55 image
must be present in flash first.

```bash
# From apps/01_pse84_tfm_m33_m55_blinki/
west flash -d cm55/build
west flash -d cm33_ns/build
```

After reset you should see the red LED blink at 1 Hz (CM33-NS) and
the green LED blink at 2 Hz (CM55).

## Console

The KitProg3 USB-UART bridge exposes the CM33-NS console at 115200
8N1. The CM55 image has no UART of its own in this configuration;
its `printk`/`printf` output is not visible on the console.

## Clean

```bash
rm -rf cm33_ns/build cm55/build
```
